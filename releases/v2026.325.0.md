# v2026.325.0

> Publicada: 2026-03-25

## Aspectos destacados

- **Importación/exportación de empresas** — Portabilidad total de empresas con una UX de explorador de archivos para importar y exportar empresas de agentes. Incluye vista previa enriquecida de frontmatter, selector de archivos anidado, soporte de historial de fusiones, referencias abreviadas de GitHub y comandos de CLI `company import`/`company export`. Las empresas importadas se abren automáticamente tras la importación, y los temporizadores de latido están deshabilitados por defecto para los agentes importados. ([#840](https://github.com/paperclipai/paperclip/pull/840), [#1631](https://github.com/paperclipai/paperclip/pull/1631), [#1632](https://github.com/paperclipai/paperclip/pull/1632), [#1655](https://github.com/paperclipai/paperclip/pull/1655))
- **Biblioteca de habilidades de empresa** — Nuevo sistema de habilidades con alcance de empresa, con UI de habilidades, sincronización de habilidades de agentes en todos los adaptadores locales (Claude, Codex, Pi, Gemini), habilidades de GitHub fijadas con comprobaciones de actualización y soporte de habilidades integradas. ([#1346](https://github.com/paperclipai/paperclip/pull/1346))
- **Rutinas y tareas recurrentes** — Motor completo de rutinas con disparadores, ejecuciones de rutina, coalescencia y portabilidad de tareas recurrentes. Incluye documentación de API y soporte de exportación de rutinas. ([#1351](https://github.com/paperclipai/paperclip/pull/1351), [#1622](https://github.com/paperclipai/paperclip/pull/1622), @aronprins)

## Mejoras

- **Solicitudes de unión en línea en la bandeja** — Las solicitudes de unión ahora se renderizan en línea en la bandeja de entrada junto a aprobaciones y otros elementos de trabajo.
- **Siembra de incorporación** — Los nuevos proyectos e issues se siembran con contexto de objetivo durante la incorporación para una mejor experiencia de primera ejecución.
- **Recuperación de instrucciones de agentes** — Las instrucciones gestionadas de agentes se recuperan del disco al iniciar; las instrucciones se conservan entre cambios de adaptador.
- **Página de ajustes de latidos** — Muestra todos los agentes sin importar la configuración de intervalo; se agregó un botón «Deshabilitar todo» para control masivo rápido.
- **Historial del agente por participación** — El historial de issues del agente ahora usa registros de participación en lugar de búsquedas directas de asignación.
- **Orden alfabético de agentes** — Los agentes se ordenan alfabéticamente por nombre en todas las vistas.
- **Assets de organigrama de empresa** — Visuales mejorados del organigrama generado para empresas.
- **Errores de conexión de API del CLI mejorados** — Mejores mensajes de error cuando el CLI no puede alcanzar la API de Paperclip.
- **Enlaces de mención en Markdown** — Los esquemas de URL personalizados ahora están permitidos en Lexical LinkNode, lo que habilita píldoras de mención con comportamiento de enlace adecuado. La eliminación atómica de píldoras de mención funciona correctamente.
- **Reutilización del espacio de trabajo del issue** — Los espacios de trabajo se reutilizan correctamente tras ejecuciones de aislamiento.
- **Reanudación de sesión de ejecución fallida** — Las sesiones explícitas de ejecuciones fallidas ahora pueden reanudarse mediante el flag honor.
- **CI de imagen Docker** — Se agregó el flujo de trabajo de compilación y despliegue de imagen Docker. ([#542](https://github.com/paperclipai/paperclip/pull/542), @albttx)
- **Filtro de proyecto en issues** — La lista de issues ahora puede filtrarse por proyecto. ([#552](https://github.com/paperclipai/paperclip/pull/552), @mvanhorn)
- **Adjuntos de imagen en comentarios en línea** — Las imágenes subidas ahora se incrustan en línea en los comentarios. ([#551](https://github.com/paperclipai/paperclip/pull/551), @mvanhorn)
- **Respaldo de AGENTS.md** — El adaptador claude-local recurre con gracia cuando falta AGENTS.md. ([#550](https://github.com/paperclipai/paperclip/pull/550), @mvanhorn)
- **Habilidad de creación de empresas** — Nueva habilidad para andamiar paquetes de empresas de agentes desde cero.
- **Renombrado de la página de informes** — Sección de informes renombrada para mayor claridad. ([#1380](https://github.com/paperclipai/paperclip/pull/1380), @DanielSousa)
- **Arranque del framework de evaluación** — Framework de evaluación basado en Promptfoo con casos de prueba YAML para pruebas sistemáticas del comportamiento de agentes. ([#832](https://github.com/paperclipai/paperclip/pull/832), @mvanhorn)
- **Autenticación del CLI del tablero** — Flujo de autenticación basado en navegador para el CLI, para que los usuarios del tablero puedan autenticarse sin copiar manualmente claves de API. ([#1635](https://github.com/paperclipai/paperclip/pull/1635))

## Guía de actualización

Siete nuevas migraciones de la base de datos (`0038`–`0044`) se ejecutarán automáticamente al iniciar:

- **La migración 0038** agrega columnas de seguimiento de procesos a las ejecuciones de latido (PID, started-at, seguimiento de reintentos).
- **La migración 0039** agrega las tablas del motor de rutinas (routines, triggers, routine runs).
- **Las migraciones 0040–0042** extienden las habilidades de empresa, las tareas recurrentes y los metadatos de portabilidad.
- **La migración 0043** agrega las columnas de managed-home de Codex y de recuperación de instrucciones de agente.
- **La migración 0044** agrega las tablas de claves de API del tablero y de desafíos de autenticación del CLI para la autenticación del CLI basada en navegador.

Todas las migraciones son aditivas (nuevas tablas y columnas): no se modifica ningún dato existente. El inicio estándar de `paperclipai` las aplicará automáticamente.

Si usas la función de importación/exportación de empresas, ten en cuenta que las empresas importadas tienen los temporizadores de latido deshabilitados por defecto. Vuelve a habilitarlos manualmente desde la página de ajustes de latidos tras verificar la configuración del adaptador.
